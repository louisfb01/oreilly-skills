# Feedback log

Your agent adds an entry after each run of the skill, newest first. When the same correction appears twice, or you state it as a rule, it moves into `SKILL.md` and the entry is marked `promoted`.

```
### YYYY-MM-DD: short title
- Asked: what you asked for, in a line.
- Corrected: what you changed or said, in your own words.
- Lesson: the rule this suggests.
- Status: logged | promoted YYYY-MM-DD
```
