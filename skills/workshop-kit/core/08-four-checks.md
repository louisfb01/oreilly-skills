## Four types, four checks
| Type | What it does | What you do |
|---|---|---|
| Intrinsic | Contradicts the source you gave | Ask for the exact quote and page |
| Extrinsic | Adds something the source never said | "Only from the document; otherwise write 'not found'" |
| Factual | Gets a fact about the world wrong | Confirm in a second source, with a link |
| Faithfulness | Ignores your instructions | New chat; put the instruction at the end |
> visual: the table as four rows; the "What you do" column in the accent colour
> notes: Each exercise later trains one of these checks. Point at the row when you get there.
