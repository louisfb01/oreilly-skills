## Steps
1. One action per step, written as a command.
2. At most 5 steps, 90 characters each.
3. Pairs: one person drives, the other checks.

## Prompt
The exact text students paste. Written in the workshop language, in the voice of
someone in the client's team. 600 characters at most. It names the file, the task,
the output format and one limit.

## Done when
A check the pair can see for themselves: a number that must match, a word that must
not appear, a column that must exist. Never "it looks good".

Optional. What to do if a file is missing or the tool blocks something.
